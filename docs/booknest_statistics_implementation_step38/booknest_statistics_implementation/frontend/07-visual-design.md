# Visual direction

Statistics must feel like BookNest, not a finance dashboard.

- Reuse existing semantic tokens, radius, surfaces, typography.
- Terracotta/warm BookNest accents.
- Limited chart vocabulary:
  - vertical bars;
  - horizontal bars;
  - heatmap;
  - segmented/progress bars;
  - comparison line.
- Avoid excessive donut/pie charts.
- Covers provide editorial visual richness.
- Insights/records use icons and typography, not traffic-light judgement colors.
- Charts must support light/dark themes if BookNest does.
- Respect reduced motion for transitions.
